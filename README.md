# Greenway Cleanup

`index.html` is the public signup site, `success.html` is its form-success page, and `netlify.toml` holds site configuration. The root favicon and manifest files are loaded by both pages. `flora/` contains SVG illustrations used by the site. `INTENT.md` and `STATUS.md` explain its purpose and current decisions.

`old images/` is the existing local screenshot archive. It is intentionally kept on disk and ignored by Git; do not move or add it to the deployed repository.
